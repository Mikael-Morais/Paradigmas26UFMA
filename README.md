# 💻 Paradigmas de Programação

Este repositório contém os exercícios, trabalhos e atividades práticas desenvolvidos para a disciplina de **Paradigmas de Programação**.

## 📌 Sobre a Disciplina

A disciplina aborda os diferentes modelos de computação e estilos de programação, explorando como os problemas podem ser estruturados e resolvidos utilizando variados paradigmas de linguagem.

---

## 📂 Conteúdo e Estrutura

Os códigos e materiais estão organizados pelas seguintes seções / tópicos:

* 🔹 **Paradigma Imperativo / Procedural** (C, Pascal, etc.)
* 🔹 **Paradigma Orientado a Objetos (POO)** (Java, C++, Python, etc.)
* 🔹 **Paradigma Funcional** (Haskell, Lisp, Elixir, etc.)
* 🔹 **Paradigma Lógico** (Prolog, etc.)

---

## 🛠️ Tecnologias & Linguagens

Dependendo da atividade, utilizam-se linguagens como:
- [C](https://en.wikipedia.org/wiki/C_(programming_language))
- [Java](https://www.java.com/)
- [Haskell](https://www.haskell.org/)
- [Prolog](https://en.wikipedia.org/wiki/Prolog)
- [Python](https://www.python.org/)
